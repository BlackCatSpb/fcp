## 5. Проблемы

1. **Переобучение**: Eval PPL (308) >> Train PPL (138) — 2.6M токенов не хватает.
2. **τ не растёт**: covariance memory не используется при L=128. Нужен L > 1000.
3. **Градиентная дыра**: grad norm на чётных чекпоинтах = 0 (report до zero_grad).
4. **Генерация галлюцинирует**: "Ганд-музей и Людмила" — смесь реальных сущностей.
